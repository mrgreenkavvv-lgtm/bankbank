# Банк «Восток» — симулятор банка

Браузерная экономическая стратегия на чистом HTML/CSS/JS: без сборки и зависимостей.

## Что внутри

- `index.html` — дашборд: капитал, KPI, ставки, живой поток, лента событий
- `clients.html` — очередь заявок и портфель (кредиты и вклады)
- `manager.html` — менеджеры, найм, курсы, повышения, автопилот
- `branches.html` — сеть филиалов и уровень банка
- `stocks.html` — биржа: доли конкурентов
- `security.html` — служба безопасности и кроты
- `cbr.html` — проверка ЦБ
- `achievements.html` — достижения
- `more.html` — настройки, плотность интерфейса, сброс прогресса

## Локальный запуск

Из-за service worker нужен http, а не file://:

```
python -m http.server 8099
```

и открыть http://127.0.0.1:8099/

## Обновления

После правок поднимайте `VERSION` в `sw.js` — иначе браузер отдаст старую версию из кэша.
